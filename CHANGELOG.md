# Changelog

All notable changes to the Ammyth VS Code extension will be documented in this file.

## 2026.1.0

Initial public release.

- Added explicit Current Work, assignment, result, evidence, and review workflows.
- Added runtime discovery through `ammyth.runtimePath`.
- Added optional `ammyth.cliPath` override.
- Added bounded assignment, evidence, and verification provider roles.
- Added runtime path containment and executable validation.
- Added stable workspace targeting across in-flight mutations.
- Preserved prepared-request validation and exact-request submission semantics.
- Kept mutation authority in the Ammyth CLI.
